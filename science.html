K-dwarfs Orbited By habitable Exoplanets (KOBE)

PI: J. Lillo Box

The KOBE experiment is a legacy radial-velocity survey using CARMENES at Calar Alto. By targeting the overlooked K dwarfs, KOBE bridges the gap between G- and M‑dwarf studies.

Team member

Calar Alto search for exoearths in M dwarfs (CARMENES)

PIs: P.J. Amado, A. Quirrenbach

CARMENES is a dual-channel high-resolution spectrograph operating at the 3.5m Calar Alto telescope, dedicated to the detection of terrestrial-mass exoplanets around M dwarfs.

Code, methods and results from projects built around stellar data.

RUNA

Machine learning Python scikit-learn pandas NumPy Matplotlib

A command-line prototype that estimates M-dwarf spectral subtype from Gaia G and 2MASS J photometry. It compares a simple colour-based model with a random forest and reports errors on held-out stars. A broader stellar-property app is planned.

KOBE stellar characterisation

Data pipelines & quality control Python Astropy NumPy SciPy Matplotlib

A pipeline for late-K dwarf spectra. It merges CARMENES echelle orders, estimates stellar parameters through spectral synthesis, and includes quality flags, diagnostic plots and benchmark-star checks. Input spectra are required separately.

Code and documentation ↗

Multiplicity in cool dwarfs

Data integration & validation Python NumPy SciPy Astropy Matplotlib pyperclip

Python code and data for a study of 22 known and newly identified multiple systems. The repository includes scripts, a data table, and figures; the paper reports 11 newly identified systems.
